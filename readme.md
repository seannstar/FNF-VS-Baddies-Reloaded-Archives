# VS Baddies Reloaded: The Content Archive

A collection of unused assets, scrapped content, and other interesting things found in Friday Night Funkin’ VS Baddies Reloaded.

## About

This repo is basically where I’m keeping track of all the unused and leftover content I’ve found while looking through the mod’s files.

So far, I’ve found unused sprites, Freeplay cards, remnants of scrapped songs and weeks, and a few things I still have no explanation for.

Some of this stuff is pretty easy to identify, while other things are a bit more weird. I’ll document what I can, include evidence where possible, and update things as I find out more.

## Contents

* evidence.md — Sources, screenshots, and other evidence.
* unused-assets/ — Unused sprites, animations, icons, cards, etc.
* removed-content/ — Scrapped songs, weeks, and related leftovers.
* unconfirmed/ — Stuff I haven’t figured out yet.
* screenshots/ — Images to go along with the findings.

More will be added as I go through the files.

## Notes

Not everything here has a confirmed explanation. I’ll try to separate what I’ve actually found from what I think it might have been or could be used for.

Some content might have been planned for future updates, but unless there’s evidence for that, it’s staying a theory.

This is an unofficial fan project. All original content belongs to its respective creators.
