# Unused Lucy Assets

### A collection of unused assets related to Lucy found across different versions of Reloaded.

## Unused Animated Icon

Version found: **1.1**

Status: **Unused** (as far as I know)

### Description

Is found inside `assets` or `mods`, in `images/misc/3-healthshit` . In Reloaded **1.0** and **1.1**, a custom healthbar sprite would be used alongside animated icons.

### Additional Information

* This icon has both an **animated variant** alongside a basic **regular/lose** expression variant.
* This icon can also be seen in the sprite for **Rehearsal**'s dialogue sprite, where it contains the dialogue boxes for *Jasmine*, *Chloe*, and an unused **Lucy** textbox, as she is not seen in Rehearsal **at all**.
## Unused Sprites

Version found: **2.1.0**
Status: **Unused** (as far as I know)

### Description

Two **unused Lucy sprites** were found in the files: a **variant** of Lucy’s normal sprite that has her **smiling** in her **poses**, and a **drunk** variant which does the same thing more or less with **Lucy** drunk. 

The sprites have their **own** animation **data**, with the second sprite having a separate **.json** file.

### Future Use

These sprites have been confirmed to be used in the **Week 2.5 Update**, specifically where in the song **Shimmer**, there’s a 50/50 **chance** you get one of these sprites, with Lucy no longer having a stern expression in this song.
