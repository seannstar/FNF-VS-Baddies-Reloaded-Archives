# Unused Freeplay Cards

A collection of unused or apparently unused Freeplay cards found in Reloaded.

## Chloe

##### Status: Unused 

An **unused Chloe card** image exists in the game **files**. It’s not used **anywhere** in the game, its intended use is **unknown**.

## Jasmine

##### Status: Unused, likely intended for **future** content

**Two Jasmine card** images have been found, including one depicting her in pajamas. These cards were reportedly shown in a post in the mod’s Game Jolt thread.

These are **likely related** to Week 3.

## Cassette Girl

##### Status: Unused (May be used in the future)

A **Cassette Girl** card image has been found in the files. Its intended use is unknown. `mods/images/cards`, if i remember correctly

## Unknown Card

##### Status: Normally unused, can make an appearance

An **unknown card** can appear if a custom song that hasn’t been properly configured for the card system gets imported via mods.
